# Tools

NSAS accessories for everyday tools and supplies around the desk. Each part hangs on any NSAS panel with standard keys.

## Coffee cup holder (`coffee-cup-holder/`)

Holder for one mini cup of freeze-dried instant coffee, an open ring that grips the cup by its taper, with two NSAS accessory holes. One variant per brand: Starbucks is done, Luckin Coffee follows. See [`coffee-cup-holder/README.md`](coffee-cup-holder/README.md).
